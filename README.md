# TEL Builds

Static GitHub Pages site for **The Emerging Light** WvW build matrix.



## Visual build preview

Individual build pages can render the official Guild Wars 2 build template (specializations, selected major traits, heal/utility/elite skills) directly in TEL's design.

Copy a build template from Guild Wars 2 and paste it into the build object in `data/builds.json`:

```json
"buildCode": "[&DQ...=]"
```

`gw2skills` remains the link to the full equipment build. GW2Skills QuickLinks and GW2 in-game build template codes are different formats; the visual preview uses the official in-game `[&...=]` code.
